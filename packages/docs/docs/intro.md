# 概览

欢迎来到 AgileJS 项目技术文档！AgileJS 是一个基于 Canvas 的图形编辑引擎及其配套的 Web 应用示例。

## 项目概览

AgileJS 包含以下核心模块：

### Canvas 引擎 (packages/core)

轻量级、高性能的图形编辑和渲染引擎，提供：
- 插件化架构，易于扩展
- 支持大规模场景（10000+ 节点）
- 完整的移动端触摸支持
- 灵活的交互控制配置

[查看引擎文档 →](/docs/canvas)

### Web 编辑器 (packages/editor)

基于 Canvas 引擎构建的完整 Web 应用示例，展示：
- 可视化编辑器实现
- 锚点系统应用
- 属性面板集成
- 实际业务场景

[查看编辑器文档 →](/docs/editor)
