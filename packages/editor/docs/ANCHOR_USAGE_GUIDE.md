# 锚点系统优化 - 使用指南

## 功能概述

本次优化从根本上解决了非等比例调整图形尺寸时锚点位置偏移的问题，通过引入**相对锚点系统**，使锚点位置相对于节点边界固定，不受任何尺寸调整影响。

## 核心改进

### 1. 相对锚点模式（推荐）

- 锚点位置基于边界百分比，而非绝对像素
- 支持 13 种预定义位置：上下左右中心 + 四个角 + 四个边侧
- 任何尺寸调整（等比/非等比/水平/垂直）都不会导致偏移

### 2. 自动默认锚点

- 新节点自动生成上、下、左、右 4 个相对锚点
- 无需手动配置，开箱即用
- 可通过 `data.showPorts = false` 禁用

### 3. 锚点显隐控制

- 通过 `node.data.showPorts` 开关控制锚点是否可见
- 隐藏后锚点仍可用于连线，仅不显示

### 4. 可视化配置界面

- 属性面板新增"锚点配置"按钮
- 支持添加/删除/编辑锚点
- 支持切换相对/绝对模式
- 实时预览配置效果

## 快速开始

### 测试示例

1. 启动项目后，在右上角示例选择器中选择 **`anchor-test`**
2. 观察 4 个不同类型的节点：
   - 蓝色矩形：使用相对锚点（上下左右）
   - 绿色圆形：自动生成默认锚点
   - 橙色菱形：隐藏锚点（showPorts=false）
   - 红色矩形：使用绝对锚点

### 验证相对锚点稳定性

1. 选中蓝色矩形节点
2. 使用右侧控制点进行非等比例缩放：
   - 水平拉伸：观察上、下锚点保持在上下边中心
   - 垂直拉伸：观察左、右锚点保持在左右边中心
   - 对角缩放：观察所有锚点保持相对位置
3. 无论如何调整，锚点始终在边界的固定相对位置

### 配置自定义锚点

1. 选中任意节点
2. 打开属性面板
3. 点击"锚点配置"按钮
4. 在弹出面板中：
   - 使用"显示锚点"开关控制可见性
   - 点击"+ 添加锚点"创建新锚点
   - 点击"编辑"展开详细配置
   - 选择"相对位置"模式并选择边界位置
   - 点击"保存"应用更改

## 使用场景

### 场景1：流程图节点

```typescript
{
  id: 'process',
  shape: 'rect',
  // ... 其他属性
  // 自动生成上下左右锚点，无需配置
}
```

### 场景2：装饰性节点

```typescript
{
  id: 'decoration',
  shape: 'circle',
  data: {
    showPorts: false // 隐藏锚点
  }
}
```

### 场景3：自定义锚点布局

```typescript
{
  id: 'custom',
  shape: 'diamond',
  ports: [
    { id: 'in', anchorMode: 'relative', anchorPosition: 'top', offset: {x:0,y:0} },
    { id: 'out1', anchorMode: 'relative', anchorPosition: 'bottom-left', offset: {x:0,y:0} },
    { id: 'out2', anchorMode: 'relative', anchorPosition: 'bottom-right', offset: {x:0,y:0} }
  ]
}
```

## 配置选项

### 锚点模式

#### 相对位置（推荐）

- **优势**：不受缩放影响，稳定可靠
- **适用**：99% 的使用场景
- **配置**：选择 13 种预定义位置之一

#### 绝对偏移

- **优势**：精确像素控制
- **适用**：特殊定制需求
- **配置**：设置 X、Y 像素偏移

### 锚点位置

**边中心**（最常用）

- top: 上边中心
- right: 右边中心
- bottom: 下边中心
- left: 左边中心

**四角**

- top-left: 左上角
- top-right: 右上角
- bottom-left: 左下角
- bottom-right: 右下角

**边侧**

- right-top: 右上侧
- right-bottom: 右下侧
- left-top: 左上侧
- left-bottom: 左下侧

**中心**

- center: 节点中心

## 性能说明

- 锚点位置计算为简单算术运算，性能开销极小
- 不影响现有渲染缓存和优化策略
- 大规模场景（1000+ 节点）无影响

## 数据迁移

旧数据无需修改，系统自动兼容：

- 未指定 `anchorMode` 的锚点按绝对模式处理
- 现有 `offset` 字段继续有效
- 可逐步迁移到相对模式

## 常见问题

### Q: 为什么选中节点后看不到锚点？

A: 选中状态下锚点被隐藏以避免与调整控制点冲突。将鼠标移到其他节点上即可看到锚点。

### Q: 如何完全隐藏某个节点的锚点？

A: 在属性面板的"锚点配置"中关闭"显示锚点"开关。

### Q: 相对锚点和绝对锚点有什么区别？

A: 相对锚点基于边界百分比，缩放时保持相对位置；绝对锚点使用固定像素偏移，缩放时会等比缩放。

### Q: 可以混用相对和绝对锚点吗？

A: 可以，同一节点的不同锚点可以使用不同模式。

### Q: 如何禁用自动生成默认锚点？

A: 设置 `node.data.showPorts = false` 或手动指定 `node.ports` 数组。
