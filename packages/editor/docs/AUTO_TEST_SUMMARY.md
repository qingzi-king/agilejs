# 自动化测试系统 - 实现总结

> 更新摘要（2025-11-11）
>
> - 统一变更接口为 `dataChanges`（基于路径写入到 `node.data` 并支持深度合并），向后兼容 `styleChanges`。
> - 为 `TargetGroup` 增加 `customAction`，允许在目标组层面执行自定义异步逻辑，且会在 `dataChanges` 生效后运行。
> - 增加 `TestStep.startNextAfter` 配置，支持在当前步骤执行一段时间后提前启动下一步骤（重叠执行）。
> - 提供静态进度动画辅助 `AutoTestManager.createLineProgressAction`，当前实现为匀速线性进度（不使用缓动）。

## 📊 技术实现

### 架构设计

```
AutoTestManager (核心引擎)
    ├── 状态管理 (运行/暂停/停止)
    ├── 步骤执行器
    ├── 动画系统 (插值 + 缓动)
    ├── 备份/恢复系统
    └── 事件系统

AutoTestPanel (UI层)
    ├── 场景选择
    ├── 控制按钮
    ├── 进度显示
    └── 状态同步
```

### 数据流

```
用户操作 → AutoTestPanel → AutoTestManager → CanvasEngine
                ↓                    ↓
            状态更新 ←─────── 事件回调
```

### 关键算法

#### 1. 动画插值

```typescript
// 线性插值
lerp(start, end, t) = start + (end - start) * t

// 缓动函数（easeInOutCubic）
ease(t) = t < 0.5 ? 4t³ : 1 - (-2t + 2)³ / 2
```

#### 2. 步骤执行

```typescript
while (hasSteps && isRunning && !isPaused) {
  executeStep(currentStep);
  await delay(step.delay);
  currentStep++;
}

if (loop) {
  currentStep = 0;
  await delay(loopDelay);
  continue;
}
```

## 🔧 使用方法

### 基础用法

```typescript
// 1. 创建管理器
const manager = new AutoTestManager(engine);

// 2. 选择场景
const scenario = predefinedScenarios[0];

// 3. 启动测试
await manager.start(scenario);
```

### 自定义场景

```typescript
const customScenario: TestScenario = {
  name: "自定义测试",
  description: "这是一个自定义场景",
  steps: [
    {
      description: "所有节点变红",
      targetId: "*",
      styleChanges: { fill: "#ef4444" },
      animated: true,
      duration: 500,
      delay: 1000,
    },
  ],
  loop: false,
};
```

### 事件监听

```typescript
manager.onStepStart = (step, index, total) => {
  console.log(`步骤 ${index + 1}/${total}: ${step.description}`);
};

manager.onScenarioComplete = (scenario) => {
  console.log(`场景完成: ${scenario.name}`);
};
```

## 📈 性能考虑

### 优化措施

1. **状态备份**
   - 仅在测试开始时备份一次
   - 使用深拷贝避免引用问题

2. **动画优化**
   - 60fps 帧率
   - 缓动函数减少计算
   - 使用 `markDirty()` 而非完全重建

3. **内存管理**
   - 停止时清理定时器
   - 释放事件监听器
   - 清空备份数据

### 性能建议

- ⚠️ 避免同时修改大量节点（>100）
- ⚠️ 动画时长控制在 1000ms 以内
- ⚠️ 循环场景注意内存占用
- ⚠️ 复杂操作使用 `customAction`
